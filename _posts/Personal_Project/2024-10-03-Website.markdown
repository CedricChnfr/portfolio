<h2 id="overview">Overview</h2>

<p>This document describes the deployment process of the static portfolio on a server using Nginx as the web server. The site is accessible via the IP address <code>192.168.X.X</code> on port <code>3000</code>.</p>

<h3>Project Information</h3>
<ul>
<li><strong>Project Name</strong>: My Portfolio</li>
<li><strong>Type</strong>: Static website</li>
<li><strong>Web Server</strong>: Nginx</li>
<li><strong>IP Address</strong>: 192.168.X.X</li>
<li><strong>Port</strong>: 3000</li>
<li><strong>Source Path</strong>: <code>/home/cedric/portfolio/_site</code></li>
<li><strong>Domain</strong>: cedric.littlenuage.com</li>
</ul>

<hr/>

<h2 id="prerequisites">Prerequisites</h2>

<p>Before starting, make sure you have:</p>
<ul>
<li>A Linux server (Ubuntu/Debian recommended)</li>
<li>Root or sudo access</li>
<li>Nginx installed</li>
<li>Site files in <code>/home/cedric/portfolio/_site</code></li>
</ul>

<hr/>

<h2 id="architecture">Architecture</h2>
</div>

<pre><code>+-------------------+
|   Client Web      |
|  192.168.X.X      |
+--------+----------+
         | Port 3000
         |
+--------v----------+
|     Nginx          |
|  Web Server        |
+--------+-----------+
         |
+--------v----------+
|  HTML Files        |
|    _site/          |
+--------------------+
</code></pre>

<div class="lang-fr">
<p><strong>Flux de requete</strong> :</p>
<ol>
<li>L'utilisateur accede a <code>http://192.168.X.X:3000</code></li>
<li>Nginx recoit la requete sur le port 3000</li>
<li>Nginx sert les fichiers statiques depuis <code>/home/cedric/portfolio/_site</code></li>
<li>Le navigateur affiche le site</li>
</ol>

<hr/>

<h2 id="installation">Installation</h2>

<h3>Etape 1 : Installer Nginx</h3>
</div>

<div class="lang-en">
<p><strong>Request Flow</strong>:</p>
<ol>
<li>User accesses <code>http://192.168.X.X:3000</code></li>
<li>Nginx receives the request on port 3000</li>
<li>Nginx serves static files from <code>/home/cedric/portfolio/_site</code></li>
<li>The browser displays the site</li>
</ol>

<hr/>

<h2 id="installation">Installation</h2>

<h3>Step 1: Install Nginx</h3>
</div>

<pre><code class="language-bash"># Update packages / Mettre a jour les paquets
sudo apt update

# Install Nginx / Installer Nginx
sudo apt install nginx -y

# Verify installation / Verifier l'installation
nginx -v
</code></pre>

<div class="lang-fr">
<h3>Etape 2 : Verifier le statut de Nginx</h3>
</div>

<div class="lang-en">
<h3>Step 2: Verify Nginx Status</h3>
</div>

<pre><code class="language-bash"># Check that Nginx is active / Verifier que Nginx est actif
sudo systemctl status nginx

# Start Nginx if needed / Demarrer Nginx si necessaire
sudo systemctl start nginx

# Enable Nginx at startup / Activer Nginx au demarrage
sudo systemctl enable nginx
</code></pre>

<div class="lang-fr">
<hr/>

<h2 id="configuration-nginx">Configuration Nginx</h2>

<h3>Creer le fichier de configuration</h3>
</div>

<div class="lang-en">
<hr/>

<h2 id="nginx-configuration">Nginx Configuration</h2>

<h3>Create the Configuration File</h3>
</div>

<pre><code class="language-bash">sudo nano /etc/nginx/sites-available/mon-portfolio</code></pre>

<div class="lang-fr">
<h3>Configuration du site</h3>
<p>Ajoutez cette configuration :</p>
</div>

<div class="lang-en">
<h3>Site Configuration</h3>
<p>Add this configuration:</p>
</div>

<pre><code class="language-nginx">server {
    # Listening port / Port d'ecoute
    listen 3000;

    # Accepted server names / Noms de serveur acceptes
    server_name 192.168.X.X cedric.littlenuage.com www.cedric.littlenuage.com;

    # Site root directory / Repertoire racine du site
    root /home/cedric/portfolio/_site;

    # Default index files / Fichiers index par defaut
    index index.html index.htm;

    # Request handling / Gestion des requetes
    location / {
        try_files $uri $uri/ =404;
    }

    # Logs (optional / optionnel)
    access_log /var/log/nginx/portfolio_access.log;
    error_log /var/log/nginx/portfolio_error.log;
}
</code></pre>

<div class="lang-fr">
<h3>Activer le site</h3>
</div>

<div class="lang-en">
<h3>Enable the Site</h3>
</div>

<pre><code class="language-bash"># Create symbolic link / Creer un lien symbolique
sudo ln -s /etc/nginx/sites-available/mon-portfolio /etc/nginx/sites-enabled/

# Verify configuration / Verifier la configuration
sudo nginx -t

# Reload Nginx / Recharger Nginx
sudo systemctl reload nginx
</code></pre>

<div class="lang-en">
<hr/>

<h2 id="deployment">Deployment</h2>

<h3>Step 1: Prepare Site Files</h3>
</div>

<pre><code class="language-bash"># Create directory if needed / Creer le repertoire si necessaire
mkdir -p /home/cedric/portfolio/_site

# Verify files exist / Verifier que les fichiers existent
ls -la /home/cedric/portfolio/_site
</code></pre>

<div class="lang-fr">
<h3>Etape 2 : Configurer les permissions</h3>
</div>

<div class="lang-en">
<h3>Step 2: Configure Permissions</h3>
</div>

<pre><code class="language-bash"># Set proper permissions / Donner les bonnes permissions
sudo chmod -R 755 /home/cedric/portfolio/_site

# Change owner (optional) / Changer le proprietaire (optionnel)
sudo chown -R www-data:www-data /home/cedric/portfolio/_site
</code></pre>

<div class="lang-fr">
<h3>Etape 3 : Configurer le pare-feu</h3>
</div>

<div class="lang-en">
<h3>Step 3: Configure the Firewall</h3>
</div>

<pre><code class="language-bash"># Allow port 3000 / Autoriser le port 3000
sudo ufw allow 3000

# Allow Nginx / Autoriser Nginx
sudo ufw allow 'Nginx Full'

# Check status / Verifier le statut
sudo ufw status
</code></pre>

<div class="lang-fr">
<h3>Etape 4 : Redemarrer Nginx</h3>
</div>

<div class="lang-en">
<h3>Step 4: Restart Nginx</h3>
</div>

<pre><code class="language-bash"># Test configuration / Tester la configuration
sudo nginx -t

# Restart Nginx / Redemarrer Nginx
sudo systemctl restart nginx

# Verify Nginx is listening on port 3000
sudo netstat -tlnp | grep 3000
</code></pre>

<div class="lang-fr">
<h3>Etape 5 : Tester le site</h3>
</div>

<div class="lang-en">
<h3>Step 5: Test the Site</h3>
</div>

<pre><code class="language-bash"># Local test / Test en local
curl http://localhost:3000

# Test with IP / Test avec l'IP
curl http://192.168.X.X:3000
</code></pre>

<h2 id="depannage">Depannage</h2>

<h3>Le site ne s'ouvre pas</h3>

<h4>1. Verifier que Nginx tourne</h4>
<p><strong>Solution</strong> : Si inactif, demarrer Nginx avec <code>sudo systemctl start nginx</code></p>

<h4>2. Verifier que le port 3000 est ouvert</h4>
<p><strong>Solution</strong> : Si le port n'est pas liste, verifier la configuration Nginx</p>

<h4>3. Consulter les logs d'erreur</h4>
</div>

<div class="lang-en">
<p>Open your browser and navigate to: <strong>http://192.168.X.X:3000</strong></p>

<hr/>

<h2 id="troubleshooting">Troubleshooting</h2>

<h3>The Site Won't Open</h3>

<h4>1. Verify Nginx is Running</h4>
<p><strong>Solution</strong>: If inactive, start Nginx with <code>sudo systemctl start nginx</code></p>

<h4>2. Verify Port 3000 is Open</h4>
<p><strong>Solution</strong>: If the port is not listed, check the Nginx configuration</p>

<h4>3. Check Error Logs</h4>
</div>

<pre><code class="language-bash"># Nginx logs
sudo tail -50 /var/log/nginx/error.log

# Site logs / Logs du site
sudo tail -50 /var/log/nginx/portfolio_error.log
</code></pre>

<div class="lang-fr">
<h4>4. Verifier les permissions</h4>
<p><strong>Solution</strong> : Corriger les permissions avec <code>sudo chmod -R 755 /home/cedric/portfolio/_site</code></p>

<h4>5. Tester la configuration Nginx</h4>
<p><strong>Solution</strong> : Si erreur de syntaxe, corriger le fichier de configuration</p>

<h4>6. Verifier le pare-feu</h4>
<p><strong>Solution</strong> : Ouvrir le port 3000 avec <code>sudo ufw allow 3000</code></p>

<h3>Erreur 404 Not Found</h3>
<ul>
<li>Verifier que <code>index.html</code> existe dans <code>/home/cedric/portfolio/_site</code></li>
<li>Verifier le chemin <code>root</code> dans la configuration Nginx</li>
</ul>

<h3>Erreur 403 Forbidden</h3>
<p>Probleme de permissions. Solution :</p>
</div>

<div class="lang-en">
<h4>4. Verify Permissions</h4>
<p><strong>Solution</strong>: Fix permissions with <code>sudo chmod -R 755 /home/cedric/portfolio/_site</code></p>

<h4>5. Test Nginx Configuration</h4>
<p><strong>Solution</strong>: If syntax error, fix the configuration file</p>

<h4>6. Check the Firewall</h4>
<p><strong>Solution</strong>: Open port 3000 with <code>sudo ufw allow 3000</code></p>

<h3>404 Not Found Error</h3>
<ul>
<li>Verify that <code>index.html</code> exists in <code>/home/cedric/portfolio/_site</code></li>
<li>Check the <code>root</code> path in the Nginx configuration</li>
</ul>

<h3>403 Forbidden Error</h3>
<p>Permission issue. Solution:</p>
</div>

<pre><code class="language-bash">sudo chmod -R 755 /home/cedric/portfolio/_site
sudo chown -R www-data:www-data /home/cedric/portfolio/_site
</code></pre>
