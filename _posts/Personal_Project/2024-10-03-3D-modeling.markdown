<li><strong>Paiement</strong> : Stripe Checkout Sessions (API REST)</li>
<li><strong>Animations</strong> : Framer Motion</li>
<li><strong>Etat global</strong> : Zustand (panier persistant via localStorage)</li>
<li><strong>Icones</strong> : Lucide React (SVG accessibles)</li>
</ul>

<p><strong>Fonctionnalites implementees</strong> :</p>
<ul>
<li>Catalogue produits statique avec pages generees statiquement (<code>generateStaticParams</code>)</li>
<li>Panier d'achat persistant entre les pages et sessions</li>

<li>Design Glassmorphism : cartes avec <code>backdrop-filter: blur</code>, degrades animes, effets glow</li>

<li>SEO complet : metadata + OpenGraph par page produit</li>
<li>Toasts de notification accessibles (<code>aria-live</code>)</li>
<li>Loading skeletons pour les routes dynamiques</li>
<li>Accessibilite : <code>focus-visible</code>, <code>role="alert"</code>, touch targets 44px, <code>prefers-reduced-motion</code></li>

<h2>Lecons apprises</h2>

<h3>L'iteration de conception est essentielle</h3>
<p>Le support de rack chauffage a traverse 10 versions, demontrant que l'iteration est une partie naturelle et necessaire d'une bonne conception. Chaque version a integre des retours et resolu des problemes specifiques.</p>

<h3>Les contraintes de fabrication orientent la conception</h3>
<p>Concevoir pour l'impression 3D necessite des considerations differentes de l'usinage CNC. Comprendre ces contraintes tot permet d'economiser du temps et des materiaux.</p>

<h3>La documentation est importante</h3>
<p>Un nommage correct des fichiers, un controle de version et une bonne organisation sont cruciaux lors de la gestion de plusieurs projets et iterations.</p>

<h3>Les tests en conditions reelles sont irremplacables</h3>
<p>Les modeles CAO peuvent sembler parfaits, mais les tests physiques revelent des problemes que la simulation peut manquer (ajustement, ergonomie, contraintes imprevues).</p>

<h3>La collaboration ameliore les resultats</h3>
<p>Plusieurs projets (piece refrigerateur, composant EDF) ont ete crees pour des personnes specifiques, montrant l'importance de comprendre les besoins des utilisateurs et de recueillir des retours.</p>

<h3>7. Simply3D — E-commerce Website for 3D Printed Parts</h3>

<p><strong>Purpose</strong>: Turn CAD-designed replacement parts into sellable products online, through a modern full-stack e-commerce website built from scratch.</p>

<p><strong>Context</strong>: The parts modeled in SolidWorks (refrigerator handle and selective cap) became the foundation of a complete commercial platform, demonstrating the full chain: <strong>CAD design → 3D printing → online sales</strong>.</p>

<p><strong>Tech Stack</strong>:</p>
<ul>
<li><strong>Framework</strong>: Next.js 16 (App Router, TypeScript, SSG/SSR)</li>
<li><strong>Styling</strong>: Tailwind CSS + custom CSS (Glassmorphism design)</li>
<li><strong>Payments</strong>: Stripe Checkout Sessions (REST API)</li>
<li><strong>Animations</strong>: Framer Motion</li>
<li><strong>State Management</strong>: Zustand (persistent cart via localStorage)</li>
<li><strong>Icons</strong>: Lucide React (accessible SVGs)</li>
</ul>

<p><strong>Features Implemented</strong>:</p>
<ul>
<li>Static product catalog with statically generated pages (<code>generateStaticParams</code>)</li>
<li>Persistent shopping cart across pages and sessions</li>
<li>Secure payments via Stripe Checkout (hosted redirect)</li>
<li>Glassmorphism design: cards with <code>backdrop-filter: blur</code>, animated gradients, glow effects</li>
<li>Entry animations, hover and interaction effects (Framer Motion)</li>
<li>Full SEO: metadata + OpenGraph per product page</li>
<li>Accessible toast notifications (<code>aria-live</code>)</li>
<li>Loading skeletons for dynamic routes</li>
<li>Accessibility: <code>focus-visible</code>, <code>role="alert"</code>, 44px touch targets, <code>prefers-reduced-motion</code></li>
<li>Legal pages: privacy policy, refund policy</li>
</ul>

<p><strong>UI/UX Methodology</strong>:</p>
<ul>
<li>Audit performed with the <strong>UI/UX Pro Max</strong> skill (161 industry-specific rules)</li>
<li>Homepage pattern: Hero → Problem → Solution → Products → Testimonials → CTA</li>
<li>Anti-patterns fixed: emojis replaced with Lucide SVGs, tap delay removed, errors accessible to screen readers</li>
</ul>

<p><strong>Products Sold</strong>:</p>
<ul>
<li><strong>Selective Cap</strong> (€4.99) — modeled in 3 versions in SolidWorks, printed in PLA</li>
<li><strong>Fridge Handle</strong> (€7.99) — replacement part in high-resistance PETG</li>
</ul>

<h2>Lessons Learned</h2>

<h3>Design Iteration is Essential</h3>
<p>The heating rack bracket went through 10 versions, demonstrating that iteration is a natural and necessary part of good design. Each version incorporated feedback and addressed specific issues.</p>

<h3>Manufacturing Constraints Drive Design</h3>
<p>Designing for 3D printing requires different considerations than CNC machining. Understanding these constraints early saves time and material.</p>

<h3>Documentation Matters</h3>
<p>Proper file naming, version control, and organization are crucial when managing multiple projects and iterations.</p>

<h3>Real-World Testing is Irreplaceable</h3>
<p>CAD models can look perfect, but physical testing reveals issues that simulation might miss (fit, ergonomics, unexpected stresses).</p>

<h3>Collaboration Improves Results</h3>
<p>Several projects (refrigerator part, EDF component) were created for specific individuals, showing the importance of understanding user needs and gathering feedback.</p>
