<h1>Energie - Semestre 3</h1>

<p><strong>Annee</strong>: 2021-2022 | <strong>Semestre</strong>: 3 | <strong>Type</strong>: Technique</p>

<hr>

<h2>PART A - Presentation Generale du Cours</h2>

<h3>Contexte et objectifs</h3>

<p>Approfondissement de l'electronique de puissance (suite S1) avec convertisseurs avances, machines electriques AC, variateurs de vitesse et energies renouvelables. Applications aux systemes modernes (vehicules electriques, energies vertes, industrie 4.0).</p>

<p><strong>Objectifs :</strong></p>
<ul>
  <li>Maitriser hacheurs (Buck, Boost, Buck-Boost), onduleurs, redresseurs</li>
  <li>Etudier machines asynchrones et synchrones</li>
  <li>Concevoir variateurs de vitesse</li>
  <li>Comprendre CEM et composants Wide Bandgap (SiC, GaN)</li>
  <li>Apprehender systemes photovoltaiques et eoliens</li>
</ul>

<h3>Prerequis</h3>
<ul>
  <li>Electronique de puissance S1 (redresseurs, hacheurs de base)</li>
  <li>Circuits AC (impedances complexes)</li>
  <li>Machines DC</li>
</ul>

<hr>

<h2>PART B: EXPERIENCE, CONTEXTE ET FONCTION</h2>

<h3>Module 1 : Convertisseurs DC-DC avances</h3>

<p><strong>Hacheurs :</strong></p>
<ul>
  <li>Buck (abaisseur) : Vout = a*Vin, mode CCM/DCM</li>
  <li>Boost (elevateur) : Vout = Vin/(1-a)</li>
  <li>Buck-Boost : Vout = -a*Vin/(1-a)</li>
  <li>Cuk, SEPIC : isolation, low ripple</li>
  <li>Dimensionnement L, C (ondulation dI, dV)</li>
</ul>

<p><strong>Regulation :</strong></p>
<ul>
  <li>PWM a frequence fixe (20-100 kHz)</li>
  <li>Controle en mode tension ou courant</li>
  <li>Boucle de retroaction (TL431, optocoupleur)</li>
</ul>

<h3>Module 2 : Onduleurs</h3>

<p><strong>Onduleurs monophases :</strong></p>
<ul>
  <li>Demi-pont : Vout = +/-Vdc/2</li>
  <li>Pont complet (H-bridge) : Vout = +/-Vdc</li>
  <li>MLI sinusoidale : commande complementaire avec temps mort</li>
  <li>Filtrage LC (harmoniques)</li>
  <li>THD (Total Harmonic Distortion)</li>
</ul>

<p><strong>Onduleurs triphases :</strong></p>
<ul>
  <li>6 interrupteurs (IGBT)</li>
  <li>MLI sinus (modulation chaque phase)</li>
  <li>MLI vectorielle (SVM) : meilleure utilisation Vdc</li>
  <li>Applications : variateurs, onduleurs solaires/eoliens</li>
</ul>

<h3>Module 3 : Machines electriques AC</h3>

<p><strong>Machine asynchrone (MAS) :</strong></p>
<ul>
  <li>Principe : champ tournant, glissement s = (ns - n)/ns</li>
  <li>Schema equivalent (resistances, reactances)</li>
  <li>Couple : Tmax au glissement s = 10-20%</li>
  <li>Demarrage : direct (I=6-8 In), etoile-triangle, variateur</li>
</ul>

<p><strong>Machine synchrone :</strong></p>
<ul>
  <li>Rotor : aimants permanents (PMSM) ou bobine</li>
  <li>Synchronisme : n = f/p (pas de glissement)</li>
  <li>Moteur brushless (BLDC) : commutation electronique</li>
  <li>Applications : VE, robotique, eolien</li>
</ul>

<p><strong>Variateurs de vitesse :</strong></p>
<ul>
  <li>Controle scalaire MAS : loi V/f constante</li>
  <li>Controle vectoriel (FOC) : decouplage flux/couple</li>
  <li>Regulation en boucle fermee (encodeur)</li>
  <li>Economie d'energie (adaptation charge)</li>
</ul>

<h3>Module 4 : Energies renouvelables</h3>

<p><strong>Photovoltaique :</strong></p>
<ul>
  <li>Caracteristique I-V panneau (Isc, Voc, Pmax)</li>
  <li>MPPT (Maximum Power Point Tracking) : Perturb &amp; Observe, Incremental Conductance</li>
  <li>Onduleurs grid-tie (injection reseau)</li>
  <li>Stockage batteries (Li-Ion, LiFePO4)</li>
</ul>

<p><strong>Eolien :</strong></p>
<ul>
  <li>Turbine &rarr; generatrice (asynchrone ou synchrone a aimants)</li>
  <li>Redresseur + bus DC + onduleur reseau</li>
  <li>Pitch control (orientation pales)</li>
</ul>

<p><strong>Stockage :</strong></p>
<ul>
  <li>Batteries : chimies (Lithium, Plomb), BMS (Battery Management System)</li>
  <li>Supercapacites : forte puissance, faible energie</li>
  <li>Hydrogene : electrolyseur, pile a combustible</li>
</ul>

<h2>PART A - General Course Overview</h2>

<h3>Context and objectives</h3>

<p>Advanced power electronics (following S1) with advanced converters, AC electrical machines, variable speed drives and renewable energies. Applications to modern systems (electric vehicles, green energies, Industry 4.0).</p>

<p><strong>Objectives:</strong></p>
<ul>
  <li>Master choppers (Buck, Boost, Buck-Boost), inverters, rectifiers</li>
  <li>Study asynchronous and synchronous machines</li>
  <li>Design variable speed drives</li>
  <li>Understand EMC and Wide Bandgap components (SiC, GaN)</li>
  <li>Understand photovoltaic and wind systems</li>
</ul>

<h3>Prerequisites</h3>
<ul>
  <li>Power electronics S1 (rectifiers, basic choppers)</li>
  <li>AC circuits (complex impedances)</li>
  <li>DC machines</li>
</ul>

<hr>

<h2>PART B: EXPERIENCE, CONTEXT AND FUNCTION</h2>

<h3>Module 1: Advanced DC-DC converters</h3>

<p><strong>Choppers:</strong></p>
<ul>
  <li>Buck (step-down): Vout = a*Vin, CCM/DCM mode</li>
  <li>Boost (step-up): Vout = Vin/(1-a)</li>
  <li>Buck-Boost: Vout = -a*Vin/(1-a)</li>
  <li>Cuk, SEPIC: isolation, low ripple</li>
  <li>L, C sizing (ripple dI, dV)</li>
</ul>

<p><strong>Regulation:</strong></p>
<ul>
  <li>Fixed frequency PWM (20-100 kHz)</li>
  <li>Voltage or current mode control</li>
  <li>Feedback loop (TL431, optocoupler)</li>
</ul>

<h3>Module 2: Inverters</h3>

<p><strong>Single-phase inverters:</strong></p>
<ul>
  <li>Half-bridge: Vout = +/-Vdc/2</li>
  <li>Full bridge (H-bridge): Vout = +/-Vdc</li>
  <li>Sinusoidal PWM: complementary drive with dead-time</li>
  <li>LC filtering (harmonics)</li>
  <li>THD (Total Harmonic Distortion)</li>
</ul>

<p><strong>Three-phase inverters:</strong></p>
<ul>
  <li>6 switches (IGBT)</li>
  <li>Sinusoidal PWM (per-phase modulation)</li>
  <li>Space Vector Modulation (SVM): better Vdc utilization</li>
  <li>Applications: drives, solar/wind inverters</li>
</ul>

<h3>Module 3: AC electrical machines</h3>

<p><strong>Asynchronous machine (induction motor):</strong></p>
<ul>
  <li>Principle: rotating field, slip s = (ns - n)/ns</li>
  <li>Equivalent circuit (resistances, reactances)</li>
  <li>Torque: Tmax at slip s = 10-20%</li>
  <li>Starting: direct (I=6-8 In), star-delta, drive</li>
</ul>

<p><strong>Synchronous machine:</strong></p>
<ul>
  <li>Rotor: permanent magnets (PMSM) or wound</li>
  <li>Synchronism: n = f/p (no slip)</li>
  <li>Brushless motor (BLDC): electronic commutation</li>
  <li>Applications: EV, robotics, wind</li>
</ul>

<p><strong>Variable speed drives:</strong></p>
<ul>
  <li>Scalar control for induction motor: V/f constant law</li>
  <li>Vector control (FOC): flux/torque decoupling</li>
  <li>Closed-loop regulation (encoder)</li>
  <li>Energy savings (load adaptation)</li>
</ul>

<h3>Module 4: Renewable energies</h3>

<p><strong>Photovoltaics:</strong></p>
<ul>
  <li>Panel I-V characteristic (Isc, Voc, Pmax)</li>
  <li>MPPT (Maximum Power Point Tracking): Perturb &amp; Observe, Incremental Conductance</li>
  <li>Grid-tie inverters (grid injection)</li>
  <li>Battery storage (Li-Ion, LiFePO4)</li>
</ul>

<p><strong>Wind energy:</strong></p>
<ul>
  <li>Turbine &rarr; generator (asynchronous or permanent magnet synchronous)</li>
  <li>Rectifier + DC bus + grid inverter</li>
  <li>Pitch control (blade orientation)</li>
</ul>

<p><strong>Storage:</strong></p>
<ul>
  <li>Batteries: chemistries (Lithium, Lead), BMS (Battery Management System)</li>
  <li>Supercapacitors: high power, low energy</li>
  <li>Hydrogen: electrolyzer, fuel cell</li>
</ul>
