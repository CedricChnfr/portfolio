<h1>Signal - S5</h1>

<p><strong>Annee</strong> : 2022-2023 (Semestre 5)<br/>
<strong>Credits</strong> : 3 ECTS<br/>
<strong>Type</strong> : Traitement du Signal</p>

<hr/>

<h2>PART A : PRESENTATION GENERALE</h2>

<h3 class="section-title">Objectifs du cours</h3>

<p>Ce cours introduit les bases du traitement du signal, couvrant l'analyse temporelle et frequentielle des signaux, les transformations mathematiques essentielles, et les methodes de traitement numerique. L'accent est mis sur les techniques permettant d'extraire l'information utile des signaux et de les filtrer.</p>

<h3 class="section-title">Competences visees</h3>

<ul>
<li>Maitriser la representation temporelle et frequentielle des signaux</li>
<li>Appliquer les transformees de Fourier, Laplace et Z</li>
<li>Analyser les systemes lineaires invariants dans le temps (LTI)</li>
<li>Comprendre l'echantillonnage et la numerisation des signaux</li>
<li>Concevoir et analyser des filtres numeriques</li>
<li>Utiliser MATLAB pour le traitement du signal</li>
<li>Interpreter les spectres frequentiels</li>
</ul>

<h3 class="section-title">Organisation</h3>

<ul>
<li><strong>Volume horaire</strong> : Cours magistraux, TD et TP MATLAB</li>
<li><strong>Evaluation</strong> : Examen ecrit + TPs notes</li>
<li><strong>Semestre</strong> : 5 (2022-2023)</li>
<li><strong>Prerequis</strong> : Mathematiques (integrales, nombres complexes), programmation de base</li>
</ul>

<h2>PART B : EXPERIENCE, CONTEXTE ET FONCTION</h2>

<h3 class="section-title">Contenu pedagogique</h3>

<p>Le cours s'articule autour de l'analyse des signaux et des systemes.</p>

<h4>1. Introduction aux signaux</h4>

<p><strong>Classification des signaux</strong> :</p>

<table>
<thead>
<tr><th>Type</th><th>Description</th><th>Exemples</th></tr>
</thead>
<tbody>
<tr><td>Continu</td><td>Variable continue dans le temps</td><td>Tension electrique, temperature</td></tr>
<tr><td>Discret</td><td>Echantillonne a intervalles reguliers</td><td>Signal numerique, donnees capteur</td></tr>
<tr><td>Periodique</td><td>Se repete identiquement</td><td>Sinusoide, signal carre</td></tr>
<tr><td>Aperiodique</td><td>Non repetitif</td><td>Impulsion, bruit</td></tr>
<tr><td>Deterministe</td><td>Previsible mathematiquement</td><td>Sinusoide, rampe</td></tr>
<tr><td>Aleatoire</td><td>Nature stochastique</td><td>Bruit, turbulences</td></tr>
</tbody>
</table>

<p><strong>Signaux de base</strong> :</p>

<p><strong>Fonction echelon unitaire</strong> : signal qui passe de 0 a 1 a un instant donne.</p>

<p><strong>Impulsion de Dirac</strong> : signal infiniment bref et infiniment intense, utilise pour caracteriser les systemes.</p>

<p><strong>Sinusoide</strong> : signal periodique de base, caracterise par amplitude, frequence et phase.</p>

<div style="text-align: center; margin: 30px 0;">
  <img src="/assets/images/courses/S5/signal/signal-sinusoidal.svg" alt="Signal sinusoidal" style="max-width: 550px; border: 1px solid #ddd; padding: 15px; border-radius: 8px; background: white;" />
  <p style="font-style: italic; color: #666; margin-top: 10px;">Figure : Representation d'un signal sinusoidal - Signal periodique de base en traitement du signal</p>
</div>

<p><strong>Signal carre</strong> : alternance entre deux niveaux, riche en harmoniques impaires.</p>

<p><strong>Operations sur les signaux</strong> :</p>

<ul>
<li>Decalage temporel : retard ou avance</li>
<li>Changement d'echelle : compression ou dilatation</li>
<li>Addition et multiplication</li>
<li>Derivation et integration</li>
<li>Convolution : operation fondamentale liant entree, systeme et sortie</li>
</ul>

<h4>2. Systemes lineaires invariants (LTI)</h4>

<p><strong>Proprietes des systemes LTI</strong> :</p>

<p><strong>Linearite</strong> : la sortie est proportionnelle a l'entree et respecte la superposition.</p>

<p><strong>Invariance temporelle</strong> : le comportement ne change pas avec le temps.</p>

<p><strong>Caracterisation par reponse impulsionnelle</strong> :</p>

<p>La reponse impulsionnelle h(t) decrit completement le systeme.</p>

<p>La sortie y(t) pour une entree x(t) se calcule par convolution :<br/>
y(t) = x(t) * h(t)</p>

<p><strong>Stabilite</strong> :</p>

<p>Un systeme est stable si toute entree bornee produit une sortie bornee (critere BIBO).</p>

<p>Condition : l'integrale du module de h(t) doit etre finie.</p>

<p><strong>Causalite</strong> :</p>

<p>Un systeme est causal si la sortie ne depend que du present et du passe.</p>

<p>Condition : h(t) = 0 pour t &lt; 0.</p>

<h4>3. Analyse de Fourier</h4>

<p><strong>Serie de Fourier</strong> :</p>

<p>Decomposition d'un signal periodique en somme de sinusoides.</p>

<p>Un signal periodique de periode T0 se decompose en :</p>
<ul>
<li>Composante continue (valeur moyenne)</li>
<li>Fondamentale a frequence F0 = 1/T0</li>
<li>Harmoniques aux frequences multiples : 2F0, 3F0, 4F0...</li>
</ul>

<p><strong>Coefficients de Fourier</strong> :</p>

<p>Chaque harmonique a une amplitude et une phase caracteristiques.</p>

<p>Forme complexe : utilise des exponentielles complexes pour simplifier les calculs.</p>

<p><strong>Exemple signal carre</strong> :</p>

<p>Un signal carre ne contient que les harmoniques impaires (F0, 3F0, 5F0...).</p>

<p>Les amplitudes decroissent en 1/n ou n est le rang de l'harmonique.</p>

<p><strong>Transformee de Fourier</strong> :</p>

<p>Generalisation aux signaux non periodiques.</p>

<p>Passage du domaine temporel au domaine frequentiel.</p>

<p><strong>Spectre d'amplitude</strong> : montre les frequences presentes dans le signal.</p>

<p><strong>Spectre de phase</strong> : indique le dephasage de chaque composante.</p>

<p><strong>Proprietes importantes</strong> :</p>

<table>
<thead>
<tr><th>Propriete</th><th>Description</th></tr>
</thead>
<tbody>
<tr><td>Linearite</td><td>Transformee d'une somme = somme des transformees</td></tr>
<tr><td>Decalage temporel</td><td>Introduit un dephasage en frequentiel</td></tr>
<tr><td>Modulation</td><td>Deplacement du spectre</td></tr>
<tr><td>Convolution</td><td>Produit des transformees</td></tr>
<tr><td>Dualite temps-frequence</td><td>Signal large en temps = etroit en frequence</td></tr>
</tbody>
</table>

<p><strong>Transformee de Fourier discrete (TFD)</strong> :</p>

<p>Version numerique pour signaux echantillonnes.</p>

<p><strong>FFT (Fast Fourier Transform)</strong> : algorithme rapide pour calculer la TFD.</p>

<p>Utilisee en pratique dans MATLAB avec la fonction <code>fft()</code>.</p>

<h4>4. Transformee de Laplace</h4>

<p><strong>Principe</strong> :</p>

<p>Extension de la transformee de Fourier incluant des signaux exponentiels croissants.</p>

<p>Variable complexe s = sigma + j*omega.</p>

<p><strong>Fonction de transfert</strong> :</p>

<p>Rapport entre sortie et entree en domaine de Laplace.</p>

<p>Permet d'analyser les systemes sans resoudre les equations differentielles.</p>

<p><strong>Poles et zeros</strong> :</p>

<p><strong>Poles</strong> : valeurs de s annulant le denominateur. Determinent la stabilite et la dynamique du systeme.</p>

<p><strong>Zeros</strong> : valeurs de s annulant le numerateur. Influencent l'amplitude de la reponse.</p>

<p><strong>Analyse de stabilite</strong> :</p>

<p>Un systeme est stable si tous ses poles ont une partie reelle negative (dans le demi-plan gauche).</p>

<p><strong>Transformations utiles</strong> :</p>

<table>
<thead>
<tr><th>Signal temporel</th><th>Transformee de Laplace</th></tr>
</thead>
<tbody>
<tr><td>Impulsion</td><td>1</td></tr>
<tr><td>Echelon</td><td>1/s</td></tr>
<tr><td>Rampe</td><td>1/s&sup2;</td></tr>
<tr><td>Exponentielle</td><td>1/(s-a)</td></tr>
<tr><td>Sinusoide</td><td>omega/(s&sup2;+omega&sup2;)</td></tr>
</tbody>
</table>

<h4>5. Echantillonnage et numerisation</h4>

<p><strong>Theoreme de Shannon-Nyquist</strong> :</p>

<p>Pour echantillonner correctement un signal, la frequence d'echantillonnage Fe doit etre au moins le double de la frequence maximale du signal.</p>

<p>Condition : Fe &gt;= 2 x Fmax</p>

<p><strong>Aliasing (repliement spectral)</strong> :</p>

<p>Si le theoreme de Shannon n'est pas respecte, les hautes frequences se replient sur les basses frequences, creant des distorsions irreversibles.</p>

<p>Solution : filtrer le signal avant echantillonnage (filtre anti-repliement).</p>

<p><strong>Quantification</strong> :</p>

<p>Conversion de l'amplitude continue en valeurs discretes.</p>

<p>Nombre de bits determine la resolution :</p>
<ul>
<li>8 bits : 256 niveaux</li>
<li>16 bits : 65536 niveaux</li>
<li>24 bits : 16 millions de niveaux</li>
</ul>

<p><strong>Bruit de quantification</strong> : erreur introduite par l'arrondi des valeurs.</p>

<h4>6. Transformee en Z</h4>

<p><strong>Principe</strong> :</p>

<p>Equivalent discret de la transformee de Laplace.</p>

<p>Utilisee pour l'analyse des systemes numeriques.</p>

<p>Variable complexe z.</p>

<p><strong>Fonction de transfert discrete</strong> :</p>

<p>Rapport entre sortie et entree en domaine Z.</p>

<p>Permet de concevoir des filtres numeriques.</p>

<p><strong>Stabilite</strong> :</p>

<p>Un systeme discret est stable si tous ses poles sont a l'interieur du cercle unite (module &lt; 1).</p>

<p><strong>Lien avec la transformee de Fourier</strong> :</p>

<p>En posant z = exp(j*omega*Te), on obtient la reponse frequentielle du systeme discret.</p>

<h4>7. Filtrage numerique</h4>

<p><strong>Types de filtres</strong> :</p>

<p><strong>FIR (Finite Impulse Response)</strong> :</p>
<ul>
<li>Reponse impulsionnelle finie</li>
<li>Toujours stables</li>
<li>Phase lineaire possible</li>
<li>Plus simple a concevoir</li>
</ul>

<p><strong>IIR (Infinite Impulse Response)</strong> :</p>
<ul>
<li>Reponse impulsionnelle infinie</li>
<li>Plus efficaces (moins de coefficients)</li>
<li>Risque d'instabilite</li>
<li>Equivalents numeriques des filtres analogiques</li>
</ul>

<p><strong>Filtres selon la bande passante</strong> :</p>

<table>
<thead>
<tr><th>Type</th><th>Fonction</th></tr>
</thead>
<tbody>
<tr><td>Passe-bas</td><td>Laisse passer les basses frequences</td></tr>
<tr><td>Passe-haut</td><td>Laisse passer les hautes frequences</td></tr>
<tr><td>Passe-bande</td><td>Laisse passer une bande de frequences</td></tr>
<tr><td>Coupe-bande</td><td>Elimine une bande de frequences</td></tr>
</tbody>
</table>

<p><strong>Specifications d'un filtre</strong> :</p>

<ul>
<li>Frequence de coupure : limite de la bande passante</li>
<li>Ondulation en bande passante : variations d'amplitude acceptables</li>
<li>Attenuation en bande attenuee : rejection des frequences indesirables</li>
<li>Bande de transition : zone de passage de la bande passante a la bande attenuee</li>
</ul>

<p><strong>Conception de filtres</strong> :</p>

<p>Methodes classiques :</p>
<ul>
<li>Butterworth : reponse plate en bande passante</li>
<li>Chebyshev : ondulation en bande passante, transition plus raide</li>
<li>Elliptique : ondulation en bande passante et attenuee, transition tres raide</li>
<li>Bessel : phase lineaire, preserve la forme du signal</li>
</ul>

<h2>PART C : ASPECTS TECHNIQUES</h2>

<h3 class="section-title">Travaux Pratiques MATLAB</h3>

<p><strong>TP1 : Decomposition en serie de Fourier</strong> :</p>

<p>Objectif : analyser un signal periodique et calculer ses coefficients de Fourier.</p>

<p>Code MATLAB typique :</p>

<pre><code class="language-matlab">% Definition du signal
tmin = 0;
tmax = 4;
T0 = tmax - tmin;
F0 = 1/T0;
dt = 0.04;
t = tmin:dt:(tmax-dt);

% Signal test (par exemple sinusoide)
A = 1;
f_t = A*sin(pi/T0*t);

% Trace du signal temporel
figure(1);
plot(t, f_t, 'r');
title('Signal temporel');
xlabel('Temps (s)');
ylabel('Amplitude');
grid;

% Calcul des coefficients de Fourier
N = 200; % Nombre d'harmoniques
rang = 0:1:N;
Fourier = zeros(N+1, 1);

% Calcul de chaque coefficient
for n = 0:N
    somme = 0;
    for k = 1:length(t)
        somme = somme + f_t(k) * exp(-2*pi*1i*n*t(k)/T0);
    end
    Fourier(n+1) = somme * dt / T0;
end

% Trace du spectre
figure(2);
stem(rang, abs(Fourier));
title('Spectre d''amplitude');
xlabel('Rang harmonique');
ylabel('Amplitude');
grid;</code></pre>

<p><strong>TP2 : Analyse d'un signal audio</strong> :</p>

<p>Traitement d'un fichier WAV pour analyse spectrale.</p>

<pre><code class="language-matlab">% Lecture du signal audio
[signal, Fe] = audioread('signal.wav');

% Parametres
tmax = length(signal) / Fe;
dt = 1/Fe;
t = 0:dt:(tmax-dt);

% Trace temporel
figure(1);
plot(t, signal);
title('Signal audio');
xlabel('Temps (s)');
ylabel('Amplitude');

% Transformee de Fourier
N = length(signal);
frequences = (0:N-1) * Fe / N;
spectre = fft(signal);

% Trace du spectre
figure(2);
plot(frequences(1:N/2), abs(spectre(1:N/2)));
title('Spectre frequentiel');
xlabel('Frequence (Hz)');
ylabel('Amplitude');
grid;</code></pre>

<p><strong>Critere de Nyquist</strong> :</p>

<p>Calcul de la frequence maximale respectant Shannon :</p>

<pre><code class="language-matlab">Fe = 44100; % Frequence d'echantillonnage
dt = 1/Fe;
Fmax = Fe/2; % Frequence de Nyquist</code></pre>

<p><strong>Generation de signaux</strong> :</p>

<pre><code class="language-matlab">t = 0:0.001:1;              % Vecteur temps

<h3 class="section-title">Concepts cles a retenir</h3>

<p><strong>Dualite temps-frequence</strong> : Un signal ne peut pas etre simultanement tres localise en temps et en frequence. Signal bref = spectre large.</p>

<p><strong>Theoreme de Shannon</strong> : Fondamental pour toute numerisation. Violer ce theoreme cree de l'aliasing irreversible.</p>

<p><strong>Convolution</strong> : Operation centrale reliant entree, systeme et sortie. En frequentiel, devient un simple produit.</p>

<h4>1. Introduction to Signals</h4>

<p><strong>Signal Classification</strong>:</p>

<p><strong>Basic Signals</strong>:</p>

<p><strong>Unit step function</strong>: a signal that transitions from 0 to 1 at a given instant.</p>

<p><strong>Dirac impulse</strong>: an infinitely brief and infinitely intense signal, used to characterize systems.</p>

<p><strong>Sinusoid</strong>: the fundamental periodic signal, characterized by amplitude, frequency, and phase.</p>

<div style="text-align: center; margin: 30px 0;">
  <img src="/assets/images/courses/S5/signal/signal-sinusoidal.svg" alt="Sinusoidal signal" style="max-width: 550px; border: 1px solid #ddd; padding: 15px; border-radius: 8px; background: white;" />

<p><strong>Square wave</strong>: alternation between two levels, rich in odd harmonics.</p>

<p><strong>Operations on signals</strong>:</p>

<ul>
<li>Time shifting: delay or advance</li>
<li>Scaling: compression or dilation</li>
<li>Addition and multiplication</li>
<li>Differentiation and integration</li>
<li>Convolution: the fundamental operation linking input, system, and output</li>
</ul>

<h4>2. Linear Time-Invariant (LTI) Systems</h4>

<p><strong>Properties of LTI systems</strong>:</p>

<p><strong>Linearity</strong>: the output is proportional to the input and obeys the superposition principle.</p>

<p><strong>Time invariance</strong>: the behavior does not change over time.</p>

<p><strong>Characterization by impulse response</strong>:</p>

<p>The impulse response h(t) completely describes the system.</p>

<p>The output y(t) for an input x(t) is computed by convolution:<br/>
y(t) = x(t) * h(t)</p>

<p><strong>Stability</strong>:</p>

<p>A system is stable if every bounded input produces a bounded output (BIBO criterion).</p>

<p>Condition: the integral of the absolute value of h(t) must be finite.</p>

<p><strong>Causality</strong>:</p>

<p>A system is causal if the output depends only on the present and past.</p>

<p>Condition: h(t) = 0 for t &lt; 0.</p>

<h4>3. Fourier Analysis</h4>

<p><strong>Fourier Series</strong>:</p>

<p>Decomposition of a periodic signal into a sum of sinusoids.</p>

<p>A periodic signal with period T0 decomposes into:</p>
<ul>
<li>DC component (average value)</li>
<li>Fundamental at frequency F0 = 1/T0</li>
<li>Harmonics at multiple frequencies: 2F0, 3F0, 4F0...</li>
</ul>

<p><strong>Fourier Coefficients</strong>:</p>

<p>Each harmonic has a characteristic amplitude and phase.</p>

<p>Complex form: uses complex exponentials to simplify calculations.</p>

<p><strong>Square wave example</strong>:</p>

<p>A square wave contains only odd harmonics (F0, 3F0, 5F0...).</p>

<p>The amplitudes decrease as 1/n where n is the harmonic order.</p>

<p><strong>Fourier Transform</strong>:</p>

<p>Generalization to non-periodic signals.</p>

<p>Transition from the time domain to the frequency domain.</p>

<p><strong>Amplitude spectrum</strong>: shows the frequencies present in the signal.</p>

<p><strong>Phase spectrum</strong>: indicates the phase shift of each component.</p>

<p><strong>Key properties</strong>:</p>

<table>
<thead>
<tr><th>Property</th><th>Description</th></tr>
</thead>
<tbody>
<tr><td>Linearity</td><td>Transform of a sum = sum of the transforms</td></tr>
<tr><td>Time shift</td><td>Introduces a phase shift in the frequency domain</td></tr>
<tr><td>Modulation</td><td>Spectrum shifting</td></tr>
<tr><td>Convolution</td><td>Product of the transforms</td></tr>
<tr><td>Time-frequency duality</td><td>Wide signal in time = narrow in frequency</td></tr>
</tbody>
</table>

<p><strong>Discrete Fourier Transform (DFT)</strong>:</p>

<p>Digital version for sampled signals.</p>

<p><strong>FFT (Fast Fourier Transform)</strong>: a fast algorithm to compute the DFT.</p>

<p>Used in practice in MATLAB with the <code>fft()</code> function.</p>

<h4>4. Laplace Transform</h4>

<p><strong>Principle</strong>:</p>

<p>Extension of the Fourier Transform to include growing exponential signals.</p>

<p>Complex variable s = sigma + j*omega.</p>

<p><strong>Transfer function</strong>:</p>

<p>Ratio between output and input in the Laplace domain.</p>

<p>Allows system analysis without solving differential equations.</p>

<p><strong>Poles and zeros</strong>:</p>

<p><strong>Poles</strong>: values of s that make the denominator zero. They determine the stability and dynamics of the system.</p>

<p><strong>Zeros</strong>: values of s that make the numerator zero. They influence the response amplitude.</p>

<p><strong>Stability analysis</strong>:</p>

<p>A system is stable if all its poles have a negative real part (in the left half-plane).</p>

<p><strong>Common transforms</strong>:</p>

<table>
<thead>
<tr><th>Time-domain signal</th><th>Laplace Transform</th></tr>
</thead>
<tbody>
<tr><td>Impulse</td><td>1</td></tr>
<tr><td>Step</td><td>1/s</td></tr>
<tr><td>Ramp</td><td>1/s&sup2;</td></tr>
<tr><td>Exponential</td><td>1/(s-a)</td></tr>
<tr><td>Sinusoid</td><td>omega/(s&sup2;+omega&sup2;)</td></tr>
</tbody>
</table>

<h4>5. Sampling and Digitization</h4>

<p><strong>Shannon-Nyquist Theorem</strong>:</p>

<p>To correctly sample a signal, the sampling frequency Fs must be at least twice the maximum frequency of the signal.</p>

<p>Condition: Fs &gt;= 2 x Fmax</p>

<p><strong>Aliasing (spectral folding)</strong>:</p>

<p>If the Shannon theorem is not satisfied, high frequencies fold back onto low frequencies, creating irreversible distortions.</p>

<p>Solution: filter the signal before sampling (anti-aliasing filter).</p>

<p><strong>Quantization</strong>:</p>

<p>Conversion of continuous amplitude values into discrete values.</p>

<p>The number of bits determines the resolution:</p>
<ul>
<li>8 bits: 256 levels</li>
<li>16 bits: 65,536 levels</li>
<li>24 bits: 16 million levels</li>
</ul>

<p><strong>Quantization noise</strong>: error introduced by rounding values.</p>

<h4>6. Z-Transform</h4>

<p><strong>Principle</strong>:</p>

<p>Discrete-time equivalent of the Laplace Transform.</p>

<p>Used for the analysis of digital systems.</p>

<p>Complex variable z.</p>

<p><strong>Discrete transfer function</strong>:</p>

<p>Ratio between output and input in the Z domain.</p>

<p>Allows the design of digital filters.</p>

<p><strong>Stability</strong>:</p>

<p>A discrete system is stable if all its poles lie inside the unit circle (magnitude &lt; 1).</p>

<p><strong>Relationship with the Fourier Transform</strong>:</p>

<p>By setting z = exp(j*omega*Te), one obtains the frequency response of the discrete system.</p>

<h4>7. Digital Filtering</h4>

<p><strong>Filter types</strong>:</p>

<p><strong>FIR (Finite Impulse Response)</strong>:</p>
<ul>
<li>Finite impulse response</li>
<li>Always stable</li>
<li>Linear phase possible</li>
<li>Simpler to design</li>
</ul>

<p><strong>IIR (Infinite Impulse Response)</strong>:</p>
<ul>
<li>Infinite impulse response</li>
<li>More efficient (fewer coefficients)</li>
<li>Risk of instability</li>
<li>Digital equivalents of analog filters</li>
</ul>

<p><strong>Filters by passband</strong>:</p>

<table>
<thead>
<tr><th>Type</th><th>Function</th></tr>
</thead>
<tbody>
<tr><td>Low-pass</td><td>Passes low frequencies</td></tr>
<tr><td>High-pass</td><td>Passes high frequencies</td></tr>
<tr><td>Band-pass</td><td>Passes a band of frequencies</td></tr>
<tr><td>Band-stop</td><td>Rejects a band of frequencies</td></tr>
</tbody>
</table>

<p><strong>Filter specifications</strong>:</p>

<ul>
<li>Cutoff frequency: passband boundary</li>
<li>Passband ripple: acceptable amplitude variations</li>
<li>Stopband attenuation: rejection of unwanted frequencies</li>
<li>Transition band: zone between the passband and the stopband</li>
</ul>

<p><strong>Filter design</strong>:</p>

<p>Classical methods:</p>
<ul>
<li>Butterworth: flat response in the passband</li>
<li>Chebyshev: ripple in the passband, steeper transition</li>
<li>Elliptic: ripple in both passband and stopband, very steep transition</li>
<li>Bessel: linear phase, preserves signal shape</li>
</ul>

<h3 class="section-title">MATLAB Lab Sessions</h3>

<p><strong>Lab 1: Fourier Series Decomposition</strong>:</p>

<p>Objective: analyze a periodic signal and compute its Fourier coefficients.</p>

<p>Typical MATLAB code:</p>

<pre><code class="language-matlab">% Signal definition
tmin = 0;
tmax = 4;
T0 = tmax - tmin;
F0 = 1/T0;
dt = 0.04;
t = tmin:dt:(tmax-dt);

% Test signal (e.g., sinusoid)
A = 1;
f_t = A*sin(pi/T0*t);

% Time-domain plot
figure(1);
plot(t, f_t, 'r');
title('Time-domain signal');
xlabel('Time (s)');
ylabel('Amplitude');
grid;

% Fourier coefficient computation
N = 200; % Number of harmonics
rang = 0:1:N;
Fourier = zeros(N+1, 1);

% Compute each coefficient
for n = 0:N
    somme = 0;
    for k = 1:length(t)
        somme = somme + f_t(k) * exp(-2*pi*1i*n*t(k)/T0);
    end
    Fourier(n+1) = somme * dt / T0;
end

% Spectrum plot
figure(2);
stem(rang, abs(Fourier));
title('Amplitude spectrum');
xlabel('Harmonic order');
ylabel('Amplitude');
grid;</code></pre>

<p><strong>Lab 2: Audio Signal Analysis</strong>:</p>

<p>Processing a WAV file for spectral analysis.</p>

<pre><code class="language-matlab">% Read audio signal
[signal, Fs] = audioread('signal.wav');

% Parameters
tmax = length(signal) / Fs;
dt = 1/Fs;
t = 0:dt:(tmax-dt);

% Time-domain plot
figure(1);
plot(t, signal);
title('Audio signal');
xlabel('Time (s)');
ylabel('Amplitude');

% Fourier Transform
N = length(signal);
frequencies = (0:N-1) * Fs / N;
spectrum = fft(signal);

% Spectrum plot
figure(2);
plot(frequencies(1:N/2), abs(spectrum(1:N/2)));
title('Frequency spectrum');
xlabel('Frequency (Hz)');
ylabel('Amplitude');
grid;</code></pre>

<p><strong>Nyquist Criterion</strong>:</p>

<p>Computing the maximum frequency satisfying Shannon:</p>

<pre><code class="language-matlab">Fs = 44100; % Sampling frequency
dt = 1/Fs;
Fmax = Fs/2; % Nyquist frequency</code></pre>
