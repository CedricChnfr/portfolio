<h2>PART A: PRÉSENTATION GÉNÉRALE</h2>

<h3>Objectifs du cours</h3>

<p>Le cours de Langage C fournit une formation complète à la programmation système en C, langage fondamental pour le développement de systèmes embarqués, systèmes d'exploitation et applications nécessitant des performances optimales. Le cours couvre les concepts fondamentaux (pointeurs, tableaux, structures) ainsi que les aspects avancés (allocation dynamique, manipulation de bits, structures de données complexes).</p>

<h3>Compétences visées</h3>

<ul>
  <li>Maîtriser la syntaxe C et les types de données</li>
  <li>Comprendre les pointeurs et l'arithmétique des pointeurs</li>
  <li>Gérer la mémoire dynamique (malloc, free)</li>
  <li>Manipuler les structures de données (listes chaînées, arbres)</li>
  <li>Réaliser des opérations bit à bit pour le bas niveau</li>
  <li>Créer des programmes modulaires avec fichiers multiples</li>
  <li>Déboguer et optimiser du code C</li>
</ul>

<h3>Organisation</h3>

<ul>
  <li><strong>Volume horaire</strong>: 48h (CM: 24h, TD/TP: 24h)</li>
  <li><strong>Évaluation</strong>: Examens écrits (60%) + TPs et projets (40%)</li>
  <li><strong>Semestre</strong>: 5 (2022-2023)</li>
  <li><strong>Prérequis</strong>: Algorithmique de base, notions de programmation</li>
</ul>

<h2>PART B: EXPÉRIENCE, CONTEXTE ET FONCTION</h2>

<h3>Contenu pédagogique</h3>

<h4>1. Fondamentaux du C</h4>

<p><strong>Types de données et opérateurs</strong>:</p>

<p>Le C propose des types primitifs de tailles fixes:</p>
<ul>
  <li><code>char</code>: 1 octet (8 bits)</li>
  <li><code>int</code>: 4 octets sur systèmes 32/64 bits</li>
  <li><code>float</code>: 4 octets (simple précision)</li>
  <li><code>double</code>: 8 octets (double précision)</li>
</ul>

<p><strong>Modificateurs</strong>: <code>signed</code>, <code>unsigned</code>, <code>short</code>, <code>long</code></p>

<p>Exemple de déclarations:</p>
<pre><code class="language-c">int nombre = 42;
unsigned int positif = 100;
char lettre = 'A';
float pi = 3.14f;
</code></pre>

<p><strong>Opérateurs bit à bit</strong>:</p>

<p>Essentiels pour la manipulation bas niveau:</p>
<ul>
  <li><code>&amp;</code> (AND), <code>|</code> (OR), <code>^</code> (XOR), <code>~</code> (NOT)</li>
  <li><code>&lt;&lt;</code> (décalage gauche), <code>&gt;&gt;</code> (décalage droite)</li>
</ul>

<p><strong>Application TD1</strong>: Compter les bits à 1 dans un entier:</p>

<pre><code class="language-c">int bitcount(int n) {
    int count = 0;
    while (n) {
        count += n &amp; 1;  // Teste le bit de poids faible
        n &gt;&gt;= 1;         // Décale d'un bit à droite
    }
    return count;
}
</code></pre>

<p>Pour <code>0xF0000F00</code>, résultat: 8 bits à 1.</p>

<p><strong>Structures de contrôle</strong>:</p>

<p>Boucles et conditionnelles standard:</p>
<pre><code class="language-c">// Tri à bulles (TD1)
for (int j = 0; j &lt; TAILLE-1; j++) {
    for (int i = 0; i &lt; TAILLE-j-1; i++) {
        if (tab[i+1] &lt; tab[i]) {
            int temp = tab[i];
            tab[i] = tab[i+1];
            tab[i+1] = temp;
        }
    }
}
</code></pre>

<h4>2. Pointeurs et Gestion Mémoire</h4>

<p><strong>Les pointeurs</strong>:</p>

<p>Concept fondamental du C: variable contenant une adresse mémoire.</p>

<p>Déclaration et utilisation:</p>
<pre><code class="language-c">int x = 10;
int *ptr = &amp;x;  // ptr pointe vers x
*ptr = 20;      // Modifie x via le pointeur
</code></pre>

<p><strong>Arithmétique des pointeurs</strong>:</p>

<pre><code class="language-c">int tab[5] = {1, 2, 3, 4, 5};
int *p = tab;  // Pointe vers tab[0]
p++;           // Pointe vers tab[1]
*p = 100;      // tab[1] = 100
</code></pre>

<p><strong>Permutation par pointeurs (TD2)</strong>:</p>

<pre><code class="language-c">int Permute(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
    return 0;
}
</code></pre>

<p><strong>Allocation dynamique</strong>:</p>

<p>Fonctions essentielles:</p>
<ul>
  <li><code>malloc(size)</code>: alloue size octets</li>
  <li><code>calloc(n, size)</code>: alloue et initialise à 0</li>
  <li><code>free(ptr)</code>: libère la mémoire</li>
</ul>

<p>Exemple TD2:</p>
<pre><code class="language-c">char* chaine = calloc(10, sizeof(char));
int* tab = calloc(10, sizeof(int));

// Utilisation...

free(chaine);
free(tab);
</code></pre>

<p><strong>Risques</strong>:</p>
<ul>
  <li>Fuite mémoire si oubli de <code>free</code></li>
  <li>Double free (libérer deux fois)</li>
  <li>Accès après free (use-after-free)</li>
  <li>Dépassement de buffer</li>
</ul>

<h4>3. Structures et Types Composés</h4>

<p><strong>Définition de structures (TD3)</strong>:</p>

<pre><code class="language-c">struct Etudiant {
    char nom[50];
    int naissance;
    int notes[10];
    int nb_notes;
};
</code></pre>

<p><strong>Utilisation</strong>:</p>

<pre><code class="language-c">struct Etudiant cedric;
strcpy(cedric.nom, "Chanfreau");
cedric.naissance = 2000;
cedric.notes[0] = 15;
</code></pre>

<p><strong>Pointeurs vers structures</strong>:</p>

<pre><code class="language-c">struct Etudiant *ptr = &amp;cedric;
ptr-&gt;naissance = 2001;  // Équivalent à (*ptr).naissance
</code></pre>

<div style="text-align: center; margin: 30px 0;">
  <img src="/assets/images/courses/S5/langage-c/pointeurs.svg" alt="Illustration des pointeurs en C" style="max-width: 500px; border: 1px solid #ddd; padding: 15px; border-radius: 8px; background: white;" />
  <p style="font-style: italic; color: #666; margin-top: 10px;">Figure : Concept des pointeurs - Un pointeur stocke l'adresse mémoire d'une variable</p>
</div>

<p><strong>Copie de structures</strong>:</p>

<p>Attention aux pointeurs dans les structures:</p>

<pre><code class="language-c">struct S1 {
    int a;
    char* ch;  // Pointeur
};

struct S1 v1, v2;
v1.ch = calloc(10, sizeof(char));
strcpy(v1.ch, "Test");

v2 = v1;  // Copie superficielle: v2.ch pointe vers la même zone!
</code></pre>

<p>Solution: copie profonde manuelle ou allocation séparée.</p>

<h4>4. Structures de Données Dynamiques</h4>

<p><strong>Listes chaînées (TP principal)</strong>:</p>

<p>Structure d'un élément:</p>
<pre><code class="language-c">struct element {
    struct Coureur* coureur;
    struct element* suiv;
};

struct liste {
    struct element* premier;
    struct element* dernier;
    struct element* courant;
};
</code></pre>

<p><strong>Initialisation</strong>:</p>
<pre><code class="language-c">int init_liste(struct liste* liste) {
    liste-&gt;premier = NULL;
    liste-&gt;dernier = NULL;
    return 0;
}
</code></pre>

<p><strong>Ajout en queue (file)</strong>:</p>
<pre><code class="language-c">int ajout_file(struct liste* der, struct Coureur* coureur) {
    if (der-&gt;dernier == NULL) {
        // Liste vide
        der-&gt;dernier = malloc(sizeof(struct element));
        der-&gt;dernier-&gt;coureur = coureur;
        der-&gt;premier = der-&gt;dernier;
        der-&gt;dernier-&gt;suiv = NULL;
    } else {
        // Ajout en fin
        der-&gt;dernier-&gt;suiv = malloc(sizeof(struct element));
        der-&gt;dernier = der-&gt;dernier-&gt;suiv;
        der-&gt;dernier-&gt;coureur = coureur;
        der-&gt;dernier-&gt;suiv = NULL;
    }
    return 0;
}
</code></pre>

<p><strong>Parcours de liste</strong>:</p>
<pre><code class="language-c">int Aller_Debut(struct liste* liste) {
    liste-&gt;courant = liste-&gt;premier;
    return 0;
}

int Avancer(struct liste* liste) {
    liste-&gt;courant = liste-&gt;courant-&gt;suiv;
    return 0;
}

int Fin(struct liste liste) {
    return (liste.courant == NULL);
}
</code></pre>

<p><strong>Comptage d'éléments</strong>:</p>
<pre><code class="language-c">int nbElement(struct liste liste) {
    int count = 0;
    while (!Fin(liste)) {
        Avancer(&amp;liste);
        count++;
    }
    return count;
}
</code></pre>

<h4>5. Fichiers et Arguments</h4>

<p><strong>Arguments de ligne de commande (TD2)</strong>:</p>

<pre><code class="language-c">int main(int argc, char* argv[]) {
    printf("Nombre d'arguments: %d\n", argc);
    if (argc == 3) {
        printf("Programme: %s\n", argv[0]);
        printf("Arg1: %s\n", argv[1]);
        printf("Arg2: %s\n", argv[2]);
    }
    return 0;
}
</code></pre>

<p>Exécution: <code>./programme arg1 arg2</code></p>

<p><strong>Manipulation de fichiers</strong>:</p>

<p>Ouverture et lecture:</p>
<pre><code class="language-c">FILE* fichier = fopen("data.txt", "r");
if (fichier == NULL) {
    perror("Erreur ouverture");
    return -1;
}

char buffer[256];
while (fgets(buffer, 256, fichier) != NULL) {
    printf("%s", buffer);
}

fclose(fichier);
</code></pre>

<p>Modes d'ouverture: <code>"r"</code> (lecture), <code>"w"</code> (écriture), <code>"a"</code> (ajout), <code>"rb"</code> (binaire)</p>

<h4>6. Programmation Modulaire</h4>

<p><strong>Projet TP: Structure modulaire</strong></p>

<p>Fichier <code>coureur.h</code>:</p>
<pre><code class="language-c">#ifndef _COUREUR_H
#define _COUREUR_H

struct Coureur {
    char* nom;
    char* prenom;
    int num_dossard;
    char* nom_equipe;
    int temps_etapes;
};

struct Coureur* Creer_Coureur(char nom[], char prenom[],
                               int dossard, char equipe[], int temps);
int Ajouter_Temps(struct Coureur* coureur, int temps_jour);
int Afficher_Coureur(struct Coureur* coureur);

#endif
</code></pre>

<p><strong>Guards d'inclusion</strong>: <code>#ifndef</code>, <code>#define</code>, <code>#endif</code> évitent les inclusions multiples.</p>

<p><strong>Compilation modulaire</strong>:</p>
<pre><code class="language-bash">gcc -Wall -c coureur.c -o coureur.o
gcc -Wall -c liste.c -o liste.o
gcc -Wall -c test_coureur.c -o test_coureur.o
gcc coureur.o liste.o test_coureur.o -o programme
</code></pre>

<h3>Outils de Développement</h3>

<p><strong>GCC (GNU Compiler Collection)</strong>:</p>

<p>Compilation de base:</p>
<pre><code class="language-bash">gcc -Wall -o programme source.c
</code></pre>

<p>Options utiles:</p>
<ul>
  <li><code>-Wall</code>: affiche tous les warnings</li>
  <li><code>-g</code>: ajoute symboles de debug</li>
  <li><code>-O2</code>: optimisation niveau 2</li>
  <li><code>-std=c99</code>: standard C99</li>
</ul>

<p><strong>GDB (GNU Debugger)</strong>:</p>

<pre><code class="language-bash">gcc -g -o programme source.c
gdb ./programme
</code></pre>

<p>Commandes GDB:</p>
<ul>
  <li><code>break main</code>: point d'arrêt</li>
  <li><code>run</code>: exécution</li>
  <li><code>next</code>: ligne suivante</li>
  <li><code>print var</code>: afficher variable</li>
  <li><code>backtrace</code>: pile d'appels</li>
</ul>

<p><strong>Valgrind (détection fuites mémoire)</strong>:</p>

<pre><code class="language-bash">valgrind --leak-check=full ./programme
</code></pre>

<p>Détecte:</p>
<ul>
  <li>Fuites mémoire (malloc sans free)</li>
  <li>Accès mémoire invalides</li>
  <li>Utilisation de mémoire non initialisée</li>
</ul>

<h3>Bonnes Pratiques</h3>

<p><strong>Gestion mémoire</strong>:</p>
<ul>
  <li>Toujours libérer ce qui est alloué</li>
  <li>Vérifier le retour de malloc</li>
  <li>Mettre les pointeurs à NULL après free</li>
</ul>

<p><strong>Code sûr</strong>:</p>
<pre><code class="language-c">char* str = malloc(100);
if (str == NULL) {
    fprintf(stderr, "Erreur allocation\n");
    return -1;
}

// Utilisation...

free(str);
str = NULL;  // Évite double free
</code></pre>

<p><strong>Organisation code</strong>:</p>
<ul>
  <li>Fichiers .h pour déclarations</li>
  <li>Fichiers .c pour implémentations</li>
  <li>Guards d'inclusion systématiques</li>
  <li>Commentaires pour fonctions complexes</li>
</ul>

<h2>PART B: EXPERIENCE, CONTEXT AND FUNCTION</h2>

<h3>Course Content</h3>

<h4>1. C Fundamentals</h4>

<p><strong>Data Types and Operators</strong>:</p>

<p>C provides fixed-size primitive types:</p>
<ul>
  <li><code>char</code>: 1 byte (8 bits)</li>
  <li><code>int</code>: 4 bytes on 32/64-bit systems</li>
  <li><code>float</code>: 4 bytes (single precision)</li>
  <li><code>double</code>: 8 bytes (double precision)</li>
</ul>

<p><strong>Modifiers</strong>: <code>signed</code>, <code>unsigned</code>, <code>short</code>, <code>long</code></p>

<p>Declaration examples:</p>
<pre><code class="language-c">int nombre = 42;
unsigned int positif = 100;
char lettre = 'A';
float pi = 3.14f;
</code></pre>

<p><strong>Bitwise Operators</strong>:</p>

<p>Essential for low-level manipulation:</p>
<ul>
  <li><code>&amp;</code> (AND), <code>|</code> (OR), <code>^</code> (XOR), <code>~</code> (NOT)</li>
  <li><code>&lt;&lt;</code> (left shift), <code>&gt;&gt;</code> (right shift)</li>
</ul>

<p><strong>TD1 Application</strong>: Count the number of 1-bits in an integer:</p>

<pre><code class="language-c">int bitcount(int n) {
    int count = 0;
    while (n) {
        count += n &amp; 1;  // Test the least significant bit
        n &gt;&gt;= 1;         // Shift one bit to the right
    }
    return count;
}
</code></pre>

<p>For <code>0xF0000F00</code>, result: 8 bits set to 1.</p>

<p><strong>Control Structures</strong>:</p>

<p>Standard loops and conditionals:</p>
<pre><code class="language-c">// Bubble sort (TD1)
for (int j = 0; j &lt; TAILLE-1; j++) {
    for (int i = 0; i &lt; TAILLE-j-1; i++) {
        if (tab[i+1] &lt; tab[i]) {
            int temp = tab[i];
            tab[i] = tab[i+1];
            tab[i+1] = temp;
        }
    }
}
</code></pre>

<h4>2. Pointers and Memory Management</h4>

<p><strong>Pointers</strong>:</p>

<p>A fundamental concept in C: a variable that holds a memory address.</p>

<p>Declaration and usage:</p>
<pre><code class="language-c">int x = 10;
int *ptr = &amp;x;  // ptr points to x
*ptr = 20;      // Modifies x through the pointer
</code></pre>

<p><strong>Pointer Arithmetic</strong>:</p>

<pre><code class="language-c">int tab[5] = {1, 2, 3, 4, 5};
int *p = tab;  // Points to tab[0]
p++;           // Points to tab[1]
*p = 100;      // tab[1] = 100
</code></pre>

<p><strong>Swap via Pointers (TD2)</strong>:</p>

<pre><code class="language-c">int Permute(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
    return 0;
}
</code></pre>

<p><strong>Dynamic Allocation</strong>:</p>

<p>Essential functions:</p>
<ul>
  <li><code>malloc(size)</code>: allocates size bytes</li>
  <li><code>calloc(n, size)</code>: allocates and initializes to 0</li>
  <li><code>free(ptr)</code>: frees the memory</li>
</ul>

<p>TD2 example:</p>
<pre><code class="language-c">char* chaine = calloc(10, sizeof(char));
int* tab = calloc(10, sizeof(int));

// Usage...

free(chaine);
free(tab);
</code></pre>

<p><strong>Risks</strong>:</p>
<ul>
  <li>Memory leak if <code>free</code> is forgotten</li>
  <li>Double free (freeing twice)</li>
  <li>Access after free (use-after-free)</li>
  <li>Buffer overflow</li>
</ul>

<h4>3. Structures and Composite Types</h4>

<p><strong>Structure Definition (TD3)</strong>:</p>

<pre><code class="language-c">struct Etudiant {
    char nom[50];
    int naissance;
    int notes[10];
    int nb_notes;
};
</code></pre>

<p><strong>Usage</strong>:</p>

<pre><code class="language-c">struct Etudiant cedric;
strcpy(cedric.nom, "Chanfreau");
cedric.naissance = 2000;
cedric.notes[0] = 15;
</code></pre>

<p><strong>Pointers to Structures</strong>:</p>

<pre><code class="language-c">struct Etudiant *ptr = &amp;cedric;
ptr-&gt;naissance = 2001;  // Equivalent to (*ptr).naissance
</code></pre>

<div style="text-align: center; margin: 30px 0;">
  <img src="/assets/images/courses/S5/langage-c/pointeurs.svg" alt="Illustration of pointers in C" style="max-width: 500px; border: 1px solid #ddd; padding: 15px; border-radius: 8px; background: white;" />
  <p style="font-style: italic; color: #666; margin-top: 10px;">Figure: Pointer concept - A pointer stores the memory address of a variable</p>
</div>

<p><strong>Structure Copying</strong>:</p>

<p>Beware of pointers inside structures:</p>

<pre><code class="language-c">struct S1 {
    int a;
    char* ch;  // Pointer
};

struct S1 v1, v2;
v1.ch = calloc(10, sizeof(char));
strcpy(v1.ch, "Test");

v2 = v1;  // Shallow copy: v2.ch points to the same memory!
</code></pre>

<p>Solution: manual deep copy or separate allocation.</p>

<h4>4. Dynamic Data Structures</h4>

<p><strong>Linked Lists (Main Lab Project)</strong>:</p>

<p>Element structure:</p>
<pre><code class="language-c">struct element {
    struct Coureur* coureur;
    struct element* suiv;
};

struct liste {
    struct element* premier;
    struct element* dernier;
    struct element* courant;
};
</code></pre>

<p><strong>Initialization</strong>:</p>
<pre><code class="language-c">int init_liste(struct liste* liste) {
    liste-&gt;premier = NULL;
    liste-&gt;dernier = NULL;
    return 0;
}
</code></pre>

<p><strong>Enqueue (Queue Insertion)</strong>:</p>
<pre><code class="language-c">int ajout_file(struct liste* der, struct Coureur* coureur) {
    if (der-&gt;dernier == NULL) {
        // Empty list
        der-&gt;dernier = malloc(sizeof(struct element));
        der-&gt;dernier-&gt;coureur = coureur;
        der-&gt;premier = der-&gt;dernier;
        der-&gt;dernier-&gt;suiv = NULL;
    } else {
        // Append at end
        der-&gt;dernier-&gt;suiv = malloc(sizeof(struct element));
        der-&gt;dernier = der-&gt;dernier-&gt;suiv;
        der-&gt;dernier-&gt;coureur = coureur;
        der-&gt;dernier-&gt;suiv = NULL;
    }
    return 0;
}
</code></pre>

<p><strong>List Traversal</strong>:</p>
<pre><code class="language-c">int Aller_Debut(struct liste* liste) {
    liste-&gt;courant = liste-&gt;premier;
    return 0;
}

int Avancer(struct liste* liste) {
    liste-&gt;courant = liste-&gt;courant-&gt;suiv;
    return 0;
}

int Fin(struct liste liste) {
    return (liste.courant == NULL);
}
</code></pre>

<p><strong>Element Counting</strong>:</p>
<pre><code class="language-c">int nbElement(struct liste liste) {
    int count = 0;
    while (!Fin(liste)) {
        Avancer(&amp;liste);
        count++;
    }
    return count;
}
</code></pre>

<h4>5. Files and Arguments</h4>

<p><strong>Command-Line Arguments (TD2)</strong>:</p>

<pre><code class="language-c">int main(int argc, char* argv[]) {
    printf("Number of arguments: %d\n", argc);
    if (argc == 3) {
        printf("Program: %s\n", argv[0]);
        printf("Arg1: %s\n", argv[1]);
        printf("Arg2: %s\n", argv[2]);
    }
    return 0;
}
</code></pre>

<p>Execution: <code>./programme arg1 arg2</code></p>

<p><strong>File Manipulation</strong>:</p>

<p>Opening and reading:</p>
<pre><code class="language-c">FILE* fichier = fopen("data.txt", "r");
if (fichier == NULL) {
    perror("Open error");
    return -1;
}

char buffer[256];
while (fgets(buffer, 256, fichier) != NULL) {
    printf("%s", buffer);
}

fclose(fichier);
</code></pre>

<p>Open modes: <code>"r"</code> (read), <code>"w"</code> (write), <code>"a"</code> (append), <code>"rb"</code> (binary)</p>

<h4>6. Modular Programming</h4>

<p><strong>Lab Project: Modular Structure</strong></p>

<p>File <code>coureur.h</code>:</p>
<pre><code class="language-c">#ifndef _COUREUR_H
#define _COUREUR_H

struct Coureur {
    char* nom;
    char* prenom;
    int num_dossard;
    char* nom_equipe;
    int temps_etapes;
};

struct Coureur* Creer_Coureur(char nom[], char prenom[],
                               int dossard, char equipe[], int temps);
int Ajouter_Temps(struct Coureur* coureur, int temps_jour);
int Afficher_Coureur(struct Coureur* coureur);

#endif
</code></pre>

<p><strong>Include Guards</strong>: <code>#ifndef</code>, <code>#define</code>, <code>#endif</code> prevent multiple inclusions.</p>

<p><strong>Modular Compilation</strong>:</p>
<pre><code class="language-bash">gcc -Wall -c coureur.c -o coureur.o
gcc -Wall -c liste.c -o liste.o
gcc -Wall -c test_coureur.c -o test_coureur.o
gcc coureur.o liste.o test_coureur.o -o programme
</code></pre>

</ul>

<p><strong>Safe Code</strong>:</p>
<pre><code class="language-c">char* str = malloc(100);
if (str == NULL) {
    fprintf(stderr, "Allocation error\n");
    return -1;
}

// Usage...

free(str);
str = NULL;  // Prevents double free
</code></pre>

<p><strong>Code Organization</strong>:</p>
<ul>
  <li>.h files for declarations</li>
  <li>.c files for implementations</li>
  <li>Systematic include guards</li>
  <li>Comments for complex functions</li>
</ul>
