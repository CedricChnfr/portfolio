# Innovative Project

## PART A: GENERALITIES

### Presentation
The Innovative Project was a collaborative effort aimed at developing a solution for detecting water leaks in a house. The project involved splitting the tasks among team members, with each person focusing on different aspects such as hardware, embedded software, mobile application, website, protocol, machine learning, server, and 3D modeling (CAD). My responsibilities included embedded software development, data retrieval from the accelerometer for leak detection, mobile application development using React Native, and 3D modeling (CAD).

## PART B: DESCRIPTIVE PART

### Experience Details

#### Environment and Context
The project was carried out in a collaborative environment, with team members working together to brainstorm ideas, design prototypes, and implement solutions. The project provided a platform to apply theoretical knowledge to practical scenarios, fostering innovation and creativity.

#### B.I.2. Your Function
In this project, I was responsible for:
- Developing the embedded software to retrieve data from the accelerometer for leak detection.
- Creating a mobile application using React Native to monitor and control the system.
- Designing 3D models (CAD) for the hardware components.

## PART C: TECHNICAL PART

### Presentation

#### Context
This section explores the technical aspects of the innovative project, focusing on the problem analysis, solution design, and prototype implementation.

### Resolution of Problem

#### What
We identified a real-life problem related to water leak detection and developed a technological solution to address it. The project involved designing and implementing a prototype to demonstrate the solution's feasibility.

#### How
1. **Problem Analysis**:
   - Conducted a thorough analysis of the problem to understand its root causes and impact.
   - Identified that traditional water leak detection methods are expensive, intrusive, and not suitable for low power IoT applications.
2. **Solution Design**:
   - Brainstormed and evaluated different technological solutions.
   - Selected a vibration-based approach leveraging external vibrations from water flow in the pipe to detect leaks with precision, using advanced signal processing.
   - Decided to use an IMU (Inertial Measurement Unit) and ESP32 for the prototype.
3. **Prototype Implementation**:
   - Designed and developed a prototype node architecture including IMU, ESP32, LoRa transceiver, and power management components.
   - Implemented signal processing and machine learning algorithms for leak detection.
   - Developed a mobile application using React Native to monitor and control the system.
   - Created 3D models (CAD) for the hardware components.
   - Tested the prototype to ensure it met the project requirements.

#### Why
To gain practical experience in solving real-life problems using technological solutions. This knowledge is crucial for developing innovative and effective solutions in a professional setting.
