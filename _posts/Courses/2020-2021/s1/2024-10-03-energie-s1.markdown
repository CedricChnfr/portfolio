## B) DESCRIPTIF

### Module 1 : Circuits courant continu

**Lois fondamentales :**
- Loi d'Ohm : U = R·I
- Loi de Kirchhoff : ΣI = 0 (nœuds), ΣU = 0 (mailles)
- Diviseur de tension, diviseur de courant

**Théorèmes :**
- Thévenin : circuit quelconque → source tension + résistance série
- Norton : circuit → source courant + résistance parallèle
- Superposition : sources multiples

**Puissance DC :**
- P = U·I = R·I² = U²/R
- Rendement η = P_utile / P_absorbée

### Module 2 : Circuits alternatifs sinusoïdaux

**Grandeurs AC :**
- Signal sinusoïdal : u(t) = U_max·sin(ωt + φ)
- Valeur efficace : U_eff = U_max / √2
- Pulsation ω = 2πf, période T = 1/f

**Impédances complexes :**
- Résistance : Z_R = R
- Inductance : Z_L = jLω (déphasage +90°)
- Condensateur : Z_C = 1/(jCω) (déphasage -90°)

**Lois AC :**
- Loi d'Ohm complexe : V = Z·I
- Association série/parallèle d'impédances

### Module 3 : Puissance en alternatif

**Triangle des puissances :**
- Puissance active : P = U·I·cos(φ) (Watts)
- Puissance réactive : Q = U·I·sin(φ) (VAR)
- Puissance apparente : S = U·I (VA), S² = P² + Q²
- Facteur de puissance : cos(φ)

**Amélioration cos(φ) :**
- Batteries de condensateurs
- Réduction pertes Joule

### Module 4 : Systèmes triphasés

**Configuration :**
- 3 phases déphasées de 120°
- Couplage étoile (Y) : U_ligne = √3·U_phase
- Couplage triangle (Δ) : I_ligne = √3·I_phase

**Puissance triphasée :**
- P = √3·U_ligne·I_ligne·cos(φ)

### Module 5 : Transformateurs monophasés

**Principe :**
- Induction mutuelle entre primaire et secondaire
- Rapport de transformation : m = N₂/N₁ = U₂/U₁

**Modèle équivalent :**
- Résistances pertes Joule
- Inductances de fuite
- Pertes fer

**Rendement :**
- η = P_sortie / P_entrée
- Maximisé à charge optimale

### Programme détaillé

#### 1. Lois fondamentales de l'électricité (10h)

**Grandeurs électriques de base :**
- Tension (V), courant (I), résistance (R)
- Conventions récepteur et générateur
- Loi d'Ohm : V = R·I
- Effet Joule : P = R·I² = V²/R

**Lois de Kirchhoff :**
- **Loi des nœuds (LKC)** : ΣI_entrantes = ΣI_sortantes
- **Loi des mailles (LKV)** : ΣV = 0 dans une boucle fermée
- Applications à l'analyse de circuits complexes

**Sources électriques :**
- Source de tension idéale et réelle (avec résistance interne)
- Source de courant idéale et réelle
- Conversion source tension ↔ source courant

#### 2. Analyse de circuits en régime continu (15h)

**Circuits résistifs :**
- Association série : R_eq = R₁ + R₂ + ... + R_n
- Association parallèle : 1/R_eq = 1/R₁ + 1/R₂ + ... + 1/R_n
- Pont diviseur de tension : V_out = V_in · R₂/(R₁+R₂)
- Pont diviseur de courant : I₁ = I_total · R₂/(R₁+R₂)

**Méthodes d'analyse systématiques :**
- **Méthode des mailles** (loi des tensions de Kirchhoff)
- **Méthode des nœuds** (loi des courants de Kirchhoff)
- Choix de la méthode selon le circuit

**Théorèmes fondamentaux :**
- **Théorème de superposition** : analyser l'effet de chaque source indépendamment
- **Théorème de Thévenin** : remplacer un circuit par V_th et R_th
- **Théorème de Norton** : remplacer un circuit par I_N et R_N
- **Théorème de Millman** : calcul de potentiel de nœud

**Ponts de mesure :**
- Pont de Wheatstone pour mesure de résistance
- Condition d'équilibre : R₁/R₂ = R₃/R₄

#### 3. Régime alternatif sinusoïdal (20h)

**Grandeurs sinusoïdales :**
- Représentation temporelle : v(t) = V_max·sin(ωt + φ)
- Valeur efficace : V_eff = V_max/√2
- Pulsation ω = 2πf, période T = 1/f
- Déphasage entre tension et courant

**Représentation complexe :**
- Notation de Fresnel : V̄ = V_eff·e^(jφ) = V_eff·(cos φ + j sin φ)
- Passage temps → complexe pour simplifier les calculs
- Représentation graphique (diagramme de Fresnel)

**Impédances complexes :**
- **Résistance** : Z̄_R = R (déphasage nul)
- **Inductance** : Z̄_L = jLω (courant en retard de 90°)
- **Condensateur** : Z̄_C = 1/(jCω) = -j/(Cω) (courant en avance de 90°)

**Loi d'Ohm complexe :**
V̄ = Z̄·Ī

**Circuits RLC :**
- Circuit série : Z̄_eq = R + jLω - j/(Cω)
- Circuit parallèle : 1/Z̄_eq = 1/R + 1/(jLω) + jCω
- Résonance : condition X_L = X_C (impédance minimale en série)

**Admittance :**
Ȳ = 1/Z̄ = G + jB (conductance G, susceptance B)

#### 4. Puissance en régime alternatif (15h)

**Puissance instantanée :**
p(t) = v(t)·i(t)

**Puissance active (W) :**
P = V_eff·I_eff·cos φ
- Puissance réellement consommée (dissipée)
- Mesurée en Watts

**Puissance réactive (VAR) :**
Q = V_eff·I_eff·sin φ
- Puissance échangée avec les éléments réactifs (L, C)
- Mesurée en VoltAmpères Réactifs

**Puissance apparente (VA) :**
S = V_eff·I_eff
- Notation complexe : S̄ = P + jQ
- Module : |S| = √(P² + Q²)

**Facteur de puissance :**
cos φ = P/S
- Varie entre 0 et 1
- Important pour l'efficacité énergétique
- Amélioration par compensation (condensateurs)

**Théorème de Boucherot :**
Dans un réseau, les puissances se somment :
- P_total = ΣP_i
- Q_total = ΣQ_i

#### 5. Transformations et équivalences (10h)

**Transformation triangle-étoile (Δ-Y) :**
Conversion entre deux configurations de résistances
- Utile pour simplifier les circuits

**Équivalent Thévenin-Norton :**
Calcul de V_th, R_th, I_N, R_N pour modéliser un circuit
- Applications : adaptation d'impédance, transfert de puissance max

**Adaptation d'impédance :**
Pour transfert maximal de puissance : Z_charge = Z_source*
(conjugué complexe)

#### MATLAB/Octave pour calculs numériques

**Calculs d'impédances complexes :**
```matlab
% Fréquence et composants
f = 1000;  % Hz
omega = 2*pi*f;
R = 1000;  % Ohm
L = 100e-3;  % H
C = 1e-6;  % F

% Impédances
Z_R = R;
Z_L = 1i * omega * L;
Z_C = 1 / (1i * omega * C);

% Impédance série RLC
Z_total = Z_R + Z_L + Z_C;

% Affichage
disp(['Module: ', num2str(abs(Z_total)), ' Ohm']);
disp(['Argument: ', num2str(angle(Z_total)*180/pi), ' degrés']);
```

**Tracé de diagramme de Bode :**
```matlab
% Fonction de transfert H(jω) = V_out/V_in
% Filtre RC passe-bas : H = 1/(1+jRCω)
R = 1000;
C = 1e-6;
f = logspace(0, 6, 1000);  % 1Hz à 1MHz
omega = 2*pi*f;

H = 1 ./ (1 + 1i*R*C*omega);

% Diagramme de Bode
subplot(2,1,1);
semilogx(f, 20*log10(abs(H)));
ylabel('Gain (dB)');
grid on;

subplot(2,1,2);
semilogx(f, angle(H)*180/pi);
ylabel('Phase (°)');
xlabel('Fréquence (Hz)');
grid on;
```

### Techniques de mesure

#### Mesure de déphasage à l'oscilloscope

**Méthode temporelle :**
1. Afficher v(t) et i(t) simultanément
2. Mesurer le décalage temporel Δt
3. Calculer le déphasage : φ = (Δt/T) × 360°

**Méthode Lissajous :**
1. Mode XY (v(t) en X, i(t) en Y)
2. Observer la forme (ellipse)
3. Déterminer φ selon l'inclinaison

#### Mesure d'impédance

**Méthode voltampèremétrique :**
- Mesurer V et I
- Calculer Z = V/I
- En AC : utiliser valeurs efficaces

**Pont d'impédances :**
- Équilibrage du pont
- Lecture directe de Z

### Applications pratiques

#### Exemple 1 : Circuit RC série

**Configuration :**
```
V_in ──R(1kΩ)──┬──C(1µF)── GND
                │
               V_out
```

**Analyse :**
- Diviseur de tension complexe
- Fonction de transfert : H = Z_C/(Z_R + Z_C)
- Filtre passe-bas
- Fréquence de coupure : f_c = 1/(2πRC) ≈ 159 Hz

**Calcul numérique :**
- À f = f_c : |H| = 1/√2 ≈ -3dB
- Phase : φ = -45°

#### Exemple 2 : Circuit RLC série - Résonance

**Configuration :**
```
V_s ──R──L──C── GND
```

**Paramètres :**
- R = 10Ω
- L = 10mH
- C = 10µF

**Fréquence de résonance :**
$$f_0 = \frac{1}{2\pi\sqrt{LC}} = \frac{1}{2\pi\sqrt{10 \times 10^{-3} \times 10 \times 10^{-6}}} \approx 1592 \text{ Hz}$$

**À la résonance :**
- Z = R (impédance minimale)
- Courant maximal : I = V_s/R
- Q = Lω₀/R (facteur de qualité)
- Surtension sur L et C

#### Exemple 3 : Compensation de puissance réactive

**Problème :**
Une charge inductive (moteur) consomme :
- P = 1000 W
- cos φ = 0.7 (inductif)
- V = 230 V, f = 50 Hz

**Objectif :** Relever le facteur de puissance à 0.95

**Calcul :**
1. Q_initial = P·tan(arccos 0.7) ≈ 1020 VAR
2. Q_final = P·tan(arccos 0.95) ≈ 329 VAR
3. Q_condensateur = Q_initial - Q_final = 691 VAR
4. C = Q_c/(ω·V²) ≈ 42 µF

**Bénéfice :**
- Réduction du courant appelé
- Amélioration de l'efficacité énergétique
- Éviter pénalités fournisseur d'énergie
