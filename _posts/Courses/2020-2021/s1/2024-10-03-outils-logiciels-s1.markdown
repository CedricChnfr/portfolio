# Outils Logiciels (OL) - Semestre 1

## 📋 Description du cours

Formation aux outils informatiques et logiciels professionnels utilisés dans le domaine de l'électronique et de l'informatique industrielle. Ce cours vise à développer l'autonomie dans l'utilisation des outils bureautiques et de documentation technique.

## 🎯 Objectifs pédagogiques

- Maîtriser les outils bureautiques professionnels
- Créer des documents techniques de qualité
- Utiliser les outils de présentation
- Gérer des données avec des tableurs
- Produire une documentation technique conforme

## 📚 Contenu du cours

### Traitement de texte
- Mise en forme de documents professionnels
- Styles et modèles
- Table des matières et index
- Insertion d'équations mathématiques
- Gestion des figures et tableaux
- Références bibliographiques

### Tableur
- Formules et fonctions avancées
- Graphiques et visualisation de données
- Tableaux croisés dynamiques
- Analyse de données
- Macros simples

### Présentation
- Création de diaporamas professionnels
- Design et mise en page
- Animations et transitions
- Support de présentation orale
- Règles de la communication visuelle

### Documentation technique
- Normes de rédaction technique
- Comptes-rendus de TP
- Rapports de projet
- Documentation de code
- Schémas et diagrammes techniques

### Outils collaboratifs
- Partage de fichiers
- Travail collaboratif en ligne
- Gestion de versions de documents
- Communication professionnelle (email, etc.)

## 💻 Logiciels utilisés

- **Microsoft Office** : Word, Excel, PowerPoint
- **LibreOffice** : Writer, Calc, Impress (alternative open source)
- **LaTeX** : Introduction à la composition de documents scientifiques
- **Outils de dessin** : Visio, Draw.io pour les schémas

## 🛠️ Projets pratiques

### Travaux pratiques
- Rédaction de comptes-rendus de TP
- Création de présentations techniques
- Analyse de données expérimentales
- Documentation de projets

### Livrables attendus
- Documents professionnels formatés
- Présentations orales avec support visuel
- Tableaux d'analyse de données
- Documentation technique complète

## 📊 Évaluation

- Qualité des comptes-rendus de TP
- Présentation orale
- Projet de documentation technique
- QCM sur les fonctionnalités des logiciels
